# Support Policy

AttendantForge 1.0 establishes the first stable behavior contract.

- Security reports: follow `SECURITY.md`.
- Bugs: include OS/compiler, exact command, exit code, detected file type, and a
  minimal non-sensitive reproducer when possible.
- 1.x releases: intended to preserve the documented CLI, exit-code meanings,
  policy precedence, and telemetry schema compatibility.
- 2.0: reserved for changes that would intentionally break those contracts.

AttendantForge does not promise complete malware detection, exact peak-memory
prediction for third-party applications, or safe execution of arbitrary embedded
content. Those are outside the project scope.
